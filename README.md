Nome do Projeto: Calculadora inteligente de consumo elétrico
Objetivo: Ajudar os usuários a estimar quanto um aparelho gasta de energia elétrica por mês, com base em dados simples de uso.
A fórmula utilizada para o cálculo foi: consumo_mensal = (potência × horasDia × 30) / 1000, onde a potência do aparelho em Watts é multiplicada pela quantidade de horas que o aparelho é utilizado por dia, multiplicada também por 30 (quantidade aproximada de dias por mês) e dividida por 1000 (conversão de Watts para quilowatt-hora )
⌨️ Instruções para utilizar o programa

Ao iniciar o programa, o usuário deverá fornecer três informações:

1. 🔌 Aparelho

Informe o nome do aparelho que deseja analisar.

Exemplo:

Informe o aparelho que está em uso: Geladeira
2. ⚡ Potência

Informe a potência do aparelho em Watts (W).

Exemplo:

Qual é a potência do aparelho em watts (W): 150
3. ⏱️ Tempo de utilização

Informe quantas horas por dia, em média, o aparelho é utilizado.

Exemplo:

Qual o tempo médio de uso diário em horas? 8

Depois dessas informações, o sistema realiza os cálculos automaticamente.
